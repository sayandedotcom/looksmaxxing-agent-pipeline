looksmaxxing.guide · pipeline demo

Evidence-checked articles, written by agents

A five-step pipeline built for looksmaxxing.guide. Each topic goes through research (an agent searching PubMed) → verify (code checks every quote against the real abstract, and a second model judges whether that abstract supports the claim) → write → editor review (a separate, stronger model looking for harm, overstatement and bad citations; loops back to the writer up to 3 times) → publish. Anything the editor never passes is held for a human instead of published.

Every run has a public trace showing what each agent saw and did.
